# AlarmApp 1.0.0

Download one ZIP:

- AlarmApp-1.0.0-Portable.zip: extract and run AlarmApp.exe.
- AlarmApp-1.0.0-Setup.zip: extract and run Install.cmd to install for the current user, create shortcuts and register uninstall support.

Supports scheduled/weekday alarms, custom interval/count reminders, current-time entry, tray operation, WAV/MP3 audio, English/Simplified Chinese, monthly usage summary and daily history. Requires Windows desktop and .NET Framework 4.8 or later; no Codex or compiler needed.

SHA256SUMS.txt is supplied for download integrity checks. User settings/history are not included in downloads. The application binary was locally compiled successfully; package contents, hashes and archive CRCs were checked. Installer/uninstaller lifecycle and executable self-tests have not been run in the restricted packaging environment. These files are unsigned.
