# AlarmApp 1.0.0

Portable download (no installation):

- AlarmApp-1.0.0-Portable.zip: extract and run AlarmApp.exe.

Supports scheduled/weekday alarms, custom interval/count reminders, current-time entry, tray operation, WAV/MP3 audio, English/Simplified Chinese, monthly usage summary and daily history. Requires Windows desktop and .NET Framework 4.8 or later; no Codex or compiler needed.

SHA256SUMS.txt is supplied for download integrity checks. User settings/history are not included in downloads. The application binary was locally compiled successfully; package contents, hashes and archive CRCs were checked. Executable self-tests and actual ringing require local verification. These files are unsigned.
