# 闹钟 · Android

支持 Android 8.0（API 26）及以上，原生 Java 项目。应用可独立运行，不要求账号，也没有联网权限。

## 功能与使用

- 定时到秒，支持单次和按星期重复；可读取当前时间。
- 间隔1–1440分钟、1–10000次，第一次在一个间隔后提醒。保存或重新启用会重置次数。
- 五种内置铃声，支持导入 WAV、MP3（单个文件最多20 MB）。导入文件复制到应用私有目录。
- 试听10秒后停止，不计入历史。设置中的响铃音量为0–100%，同时受系统闹钟音量影响；0%仍保留响铃振动。
- 世界时钟支持添加、移除时区，按城市/时区英文名称搜索。
- 秒表显示累计分钟、秒和毫秒，支持暂停、继续、重置；计数依赖系统时间，手动改时间会影响结果。
- 倒计时按分钟设置，支持暂停、继续、重置，到时使用已有闹钟响铃页面，也会出现在闹钟列表。
- 中英文切换保存在设置中；简要按月统计，详细按日查询。

## 权限和后台行为

按首页提示允许闹钟与提醒、通知；全屏权限用于锁屏响铃页面。权限缺失会影响相应功能。关闭应用页面不会取消已启用的提醒，关机不会响铃。部分设备需要允许后台运行。

重启后首次解锁时恢复调度。过期的定时提醒在重启恢复时重新计算；过期的间隔提醒从恢复后一个间隔开始，不连续补响。系统强行停止后，应重新打开应用恢复调度。

## 数据与统计

数据保存在应用私有目录，当前不与 Windows 同步。卸载或清除数据会删除设置、导入铃声和历史；删除某个闹钟会保留其历史。

使用时长是闹钟保持启用的经过时间，包含后台，关机或强行停止期间也可能纳入启用会话；它不是屏幕使用时间或秒表记录。倒计时按单次定时闹钟记录。多个闹钟分别累计，跨日、跨月按查询区间裁剪。详细页的会话响铃次数是完整会话累计，不一定只属于选定那一天。

响铃时长按响铃服务存活期间记录，每30秒保存检查点。异常退出后以最近的检查点恢复记录，可能存在尾部时间误差。

## 构建

用 Android Studio 打开本目录，配置 JDK 17、SDK Platform 35、Build Tools 35.0.0。项目使用 Gradle 8.11.1 Wrapper，首次同步需要下载构建依赖。SDK 路径放在本机 local.properties 中，不提交仓库。

在本目录执行：

```powershell
.\gradlew.bat testDebugUnitTest lintDebug assembleDebug
```

APK 输出为 app/build/outputs/apk/debug/app-debug.apk。此路径相对于本 Android 项目目录。

Windows 下也可运行 BuildAndroid.cmd / VerifyAndroid.cmd；验证入口读取 Gradle 测试报告，测试、lint和打包全部通过后导出 APK 与校验文件。导出位置由脚本计算，以日志和 verification/result.json 中 deliveryApk 为准；仓库不包含聊天中的 outputs/BuildAndroid.cmd。

验证脚本优先使用项目专用 .toolchain，或 JAVA_HOME 指定的 JDK。其他电脑需要自行配置环境；如 SDK 不在默认位置，运行 VerifyAndroid.ps1 时使用 -SdkHome 指定。不要提交工具链、Gradle缓存、签名密钥或 APK。

当前测试包为调试签名。正式发行应生成维护者签名的 APK，并保留同一签名密钥用于后续升级。
